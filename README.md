## 💡 About
**Leap Hero** is a 2D platformer developed using Unity as part of the CPCS 494 coursework. The game combines physics-based movement, collectible power-ups, and custom particle effects to create a more engaging gameplay experience.

## ✨ Features
- 🦘 **Player Movement** — Jump and navigate through the level using Unity's 2D physics.
- 🌫️ **Landing Effect** — Custom particle system triggered when the player lands.
- 💎 **Gem Power-Up** — Collect gems to temporarily enhance player abilities.
- 🚀 **Jump Boost** — Increased jump force during the power-up state.
- 🟢 **Visual Feedback** — Player color and pulsing effects indicate the active power-up via Coroutines.
- ⏱️ **Timed Ability** — Power-up effects automatically revert after 30 seconds.

## 🛠️ Built With
- **Unity 6**
- **C#**
- **Rigidbody2D & Colliders**
- **Particle System**
- **Coroutines**
