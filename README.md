## 💡 About

**Leap Hero** is a 2D platformer developed using Unity. The game combines physics-based movement, collectible power-ups, and particle effects to create a more engaging gameplay experience.

## ✨ Features

- 🦘 **Player Movement** — Jump and navigate through the level using Unity's 2D physics.
- 🌫️ **Landing Effect** — Particle effect triggered when the player lands.
- 💎 **Gem Power-Up** — Collect gems to temporarily enhance the player's abilities.
- 🚀 **Jump Boost** — Increased jump force during the power-up.
- 🟢 **Visual Feedback** — Player color and pulsing effects indicate the active power-up.
- ⏱️ **Timed Ability** — Power-up effects automatically revert after 30 seconds.

## 🛠️ Built With

- **Unity**
- **C#**
- **Rigidbody2D & Colliders**
- **Particle System**
- **Coroutines**
